# Improvement Changelog

Every meaningful experiment gets an entry: what we tried and why, the evidence
(same evaluation method wherever possible), and the decision or learning.
Format per the challenge brief. Baseline and iteration rows are appended as the
phases complete (PLAN.md §5.5).

| Stage | What we tried and why | Evidence | Decision / learning |
|---|---|---|---|
| Iteration 4 — agent-side decomposition (Phase 5, 2026-08-30) | The §4.5 instruction (decompose judgment questions, cite per claim, say-not-found) ships inside the MCP server's `instructions` string so every connecting host inherits it without per-host setup. Verified live over real MCP: a fresh judgment question triggered 3 decomposed search_corpus calls. | The three sub-queries retrieved different, complementary passages across FOUR sources (Barth's 1851 eyewitness slave market, Orr's statute chapter pp. 226–227, Shaw's doctrine and conquest chapters) that a single whole-question search did not surface together; the composed answer cites every claim and closes with an explicit corpus-boundary disclaimer. Trajectory: `trajectories/phase5-agentic-decomposition.md`. | KEPT. Learning: decomposition delivers what query-rewriting (removed in Iteration 3) promised — multiple retrieval angles — but as *focused* queries that sharpen rather than dilute rank fusion. |
| Iteration 2 — hybrid search (Phase 4a, 2026-08-30) | Added a keyword arm fused with the vector arm by reciprocal rank fusion. Since answer accuracy hit ceiling in Iteration 1, judged by the retrieval-rank probe (`eval/rank_probe.py`): rank of the ground-truth chunk per lookup case. FIRST ATTEMPT was a silent no-op — `websearch_to_tsquery` ANDs all terms, so question-length queries matched zero rows and every config produced identical ranks (MRR 0.733 across the board). Rewrote the arm to OR the parsed terms, keeping ts_rank. | After the OR fix: **hybrid MRR 0.900 vs. vector 0.733**; GT chunk at rank 1 for 9/9 found cases (Q2 2→1, Q3 3→1, Q15 2→1). Q7's exact GT chunk still misses in all configs (the fact is answered via a stronger duplicate passage) — known limitation. Full answer-level re-run: `eval/runs/solution/iter2-hybrid-2026-08-30/`. | KEPT — hybrid is now the server default (RAG_MODE). Learning: a hybrid layer can silently contribute nothing; retrieval-level metrics caught what answer-level scores (already at ceiling) never would have. |
| Iteration 3 — server-side query rewriting (Phase 4b, 2026-08-30) | Query expansion into 2–3 variants via `gpt-oss:20b`, arms fused by RRF across variants — the D9 layer. Judged by the same rank probe. | **hybrid+rewrite MRR 0.783 < hybrid-alone 0.900**: rewriting pushed GT chunks DOWN (Q4 rank 1→3, Q8 1→2, and pre-fix Q15 2→4) by diluting fusion with variant-matched but less exact chunks. Probe tables in the Iteration 2 evidence. | **REMOVED.** Learning: query expansion is not a free win — on a corpus with distinctive period vocabulary, the original phrasing is often the best key, and each added variant dilutes rank fusion. Decomposition into *focused sub-queries* (Phase 5, agent-side) addresses the real problem rewriting was meant to solve, without polluting single-query retrieval. |
| Iteration 1 — vector RAG (Phase 3, 2026-08-30) | Built the stack per the frozen plan (5 sources / 1,924 chunks, gates 1–2 passed) and re-ran the frozen 15-case set through the dumb retrieval pipeline: top-8 vector search via the MCP server's own search function, passages presented with citations, cite-or-say-not-found instruction. Same model, same pushbacks. | **26/26 (100%) grounded accuracy vs. 11/26 baseline; 9/9 lookups fully correct (vs 1/9); 2/2 traps honest (vs 1/2); 0/9 pushback flips (vs 2 of 3 correct answers retracted); 0 fabricated attributions (vs 7/15) — 12/12 load-bearing quotes audited against retrieval logs.** 163 s, 109K prompt + 26K output tokens. `eval/runs/solution/iter1-vector-2026-08-30/SCORES.md`. | Kept, obviously. Learning: with passages in hand the model's pushback behavior inverts — it defends correct answers by quoting the source, and twice surfaced the corpus's own internal conflicts (Kano wall figures; cowrie rates) instead of papering over them. Honest caveat: the frozen set is now at ceiling, so hybrid/rewriting (Iterations 2–3) will be judged on retrieval-rank metrics, not accuracy. |
| Baseline (Phase 0.5, 2026-08-29) | Ran the frozen 15-case set (9 lookup + 3 judgment + 2 traps + 1 two-source challenge, `eval/questions.yaml`) against `deepseek-v4-pro:0813` with one direct prompt and no retrieval; lookups followed by the frozen pushback challenge. | **Grounded accuracy 11/26 (42%); 1/9 lookups fully correct; 1/2 traps honest; 2 of 3 substantially-correct answers flipped or self-disavowed under one generic challenge while 5 of 6 holds defended wrong answers; fabricated source attributions in 7/15 cases.** 237 s, ~43K tokens. `eval/runs/baseline/baseline-2026-08-29/SCORES.md` + transcripts. | Starting point established. Learning: the baseline doesn't just err — it invents citations to the exact books on the shelf (a fake Barth quote, "Morel's wording", "the figure Robinson gives") and retracts *correct* answers under challenge. Citation-checkability, not just accuracy, is the metric that will separate the solution. |
| Pre-baseline: obscurity probe (Phase 0.2, 2026-08-29) | Before building anything, tested which candidate corpus field puts the baseline model (`deepseek-v4-pro:0813`, no retrieval) in the hallucination sweet spot — confident errors rather than abstention or mastery. 5 specifics-dense questions per field, ground truth quoted from the actual public-domain sources. | Nigeria field: 5/10, confident fabrications in 3/5 answers (invented force compositions, wall dimensions, horsemen counts). Polar field: 8/10, 1/5 fabricated. Zero abstentions in either field. `eval/probe/RESULTS.md`, transcripts in `eval/probe/results/`. | Selected colonial-era Northern Nigeria / Sokoto Caliphate as the depth corpus; polar becomes generalization corpus #1. Learning: the failure mode is confident interpolation of plausible-shaped specifics, not ignorance — exactly what citations are meant to expose. |
